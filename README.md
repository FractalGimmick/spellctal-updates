# spellctal-updates

Spellctal(Windows デスクトップアプリ)の更新マニフェスト。

アプリは起動時に `latest.json` を取得し、`version` が自分の版より新しければ
「新しいバージョンがあります」と表示して BOOTH の商品ページを開く導線を出す。
**自動ダウンロード・自動インストールはしない**(BOOTH の購入ゲートと両立しないため)。

## 🔴 告知の順序(これを守らないと「ダウンロードしても古いまま」の通知が飛ぶ)

BOOTH へのバイナリ登録は手動で、GitHub のリリースからラグがある。
**告知 = `latest.json` の `version` を書き換えること**なので、順序を守れば安全側に倒れる。

1. GitHub でタグ → ビルド → Windows インストーラができる
2. **BOOTH の商品ページに新しいインストーラを登録し、公開状態を確認する**
   (購入者側のダウンロードが新しいものになっていること)
3. ここで初めて告知する:
   ```bash
   ./publish.py --version 0.7.0 --notes "字幕編集(ベータ)を追加しました。" --booth-ok
   ```
4. ②がまだなら **何もしない**(告知しない = 通知は出ない。忘れても無害な側に倒れる)

`publish.py` は `--booth-ok` が無いと書き換えない(②を済ませた人の宣言)。

告知を間違えて早く出した場合は、`version` を現行版に戻して取り下げる。
※ ただし「後で」を押した利用者は、同じ版では再通知されない(押した版を記憶するため)。
　 取り下げるより、BOOTH の登録を先に済ませてから告知するのが正しい。

## フィールド

- `version` … **必須**。アプリのバージョンと比較される(`0.7.0` / `v0.7.0` どちらでも可、`X.Y.Z` の3要素必須)
- `notes` … 任意。アプリ内バナーに1行で出る
- `url` … BOOTH 商品ページ。未設定ならアプリ既定の購入ページを使う
- `published_at` … 告知した時刻(人のための記録。アプリは無視する)

未知フィールドはアプリ側で無視される。

## 注意

- **この URL は公開済み API**。既存インストールが参照し続けるので、リポジトリ名・パスを変えない
- 個人情報は受け取らない(アプリは User-Agent 以外を送らない)
- BOOTH の商品 JSON には更新日時・バージョンが無いため、**「新バイナリが登録済みか」を外から機械的に確認する方法は無い**
