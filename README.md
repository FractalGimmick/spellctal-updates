# spellctal-updates

Spellctal(Windows デスクトップアプリ)の更新マニフェスト。

アプリは起動時に `latest.json` を取得し、`version` が自分の版より新しければ
「新しいバージョンがあります」と表示して BOOTH の商品ページを開く導線を出す。
**自動ダウンロード・自動インストールはしない**(BOOTH の購入ゲートと両立しないため)。

## 🔴 告知の順序(これを守らないと「ダウンロードしても古いまま」の通知が飛ぶ)

BOOTH へのバイナリ登録は手動で、GitHub のリリースからラグがある。
**告知 = `latest.json` の `version` を書き換えること**なので、順序を守れば安全側に倒れる。

1. GitHub でタグ → ビルド → Windows インストーラができる
2. **BOOTH の商品ページに新しいインストーラを登録し、公開状態を確認する**
   (購入者側のダウンロードが新しいものになっていること)
3. ここで初めて告知する:
   ```bash
   ./publish.py --version 0.7.0 --notes "字幕編集(ベータ)を追加しました。" --booth-ok
   ```
4. ②がまだなら **何もしない**(告知しない = 通知は出ない。忘れても無害な側に倒れる)

`publish.py` は `--booth-ok` が無いと書き換えない(②を済ませた人の宣言)。

告知を間違えて早く出した場合は、`version` を現行版に戻して取り下げる。
※ ただし「後で」を押した利用者は、同じ版では再通知されない(押した版を記憶するため)。
　 取り下げるより、BOOTH の登録を先に済ませてから告知するのが正しい。

## GitHub Actions から告知する(推奨)

Actions タブ →「Publish update notice」→ Run workflow。CLI なら:

```bash
gh workflow run publish-update.yml \
  -f version=0.7.0 \
  -f notes="字幕編集(ベータ)を追加しました。" \
  -f booth_ok=true
```

ガード(すべて実測済み):

- `booth_ok` が false だと**何もせず失敗**(安全側)
- 商品URLから item id を取り、`https://booth.pm/ja/items/<id>.json` が **200 でなければ告知せず失敗**
  (商品ページが未公開・未登録の検知。※ファイルだけ古い、までは外から分からない)
- `dry_run=true` で内容確認だけ、`skip_booth_preflight=true` で公開チェックを飛ばせる(通常は不要)
- 同じ内容の再実行は「変更なし」で終わる(安全に何度でも実行できる)
- push に失敗したら**赤くなる**(緑なのに未反映、を防ぐ)

## BOOTH の商品ページに「版」を出す(重要)

BOOTH の商品ページには**バージョンや更新日を示すフィールドがありません**(商品 JSON で実測:
`name` / `description` / `published_at` のみ)。そのため、こちらで書かないと購入者は
「今ダウンロードするのが新しい版かどうか」を判別できません。

- **商品説明の冒頭に必ず書く**(告知ワークフローが検査し、無ければ告知を止めます):

  ```
  ■ 最新版: v0.7.0(2026-11-02 更新)
  字幕編集(ベータ)を追加しました。
  ```

  告知を実行すると Actions のサマリにこの文がそのまま出るので、コピーして BOOTH に貼る。

- **商品名にバージョンを入れる必要はありません**(毎回名前を変えると、一覧・ブックマーク・
  購入履歴の見え方がぶれやすい)。説明文の冒頭で十分。一覧で判別したい場合のみ `Spellctal v0.7.0` 形式も可
- **インストーラのファイル名には版が入ります**(`spellctal_0.7.0_x64-setup.exe`)。
  購入後のダウンロード一覧で版が分かります
- アプリ側もフッターに現在の版(`v0.6.2 製品版`)を出しているので、両方を見比べられます

## フィールド

- `version` … **必須**。アプリのバージョンと比較される(`0.7.0` / `v0.7.0` どちらでも可、`X.Y.Z` の3要素必須)
- `notes` … 任意。アプリ内バナーに1行で出る。**空ならアプリ側が「BOOTH から最新版を入手できます。」を出す**
  (プレースホルダを書かない。省略すると空で書かれ、前回の文は引き継がない)
- `url` … BOOTH 商品ページ。未設定ならアプリ既定の購入ページを使う
- `published_at` … 告知した時刻(人のための記録。アプリは無視する)

未知フィールドはアプリ側で無視される。

## 注意

- **この URL は公開済み API**。既存インストールが参照し続けるので、リポジトリ名・パスを変えない
- 個人情報は受け取らない(アプリは User-Agent 以外を送らない)
- BOOTH の商品 JSON には更新日時・バージョンが無いため、**「新バイナリが登録済みか」を外から機械的に確認する方法は無い**
